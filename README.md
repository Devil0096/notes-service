# notes-service

Сервис заметок — учебный проект по Git.

## О проекте
Backend-сервис для создания, редактирования и хранения
пользовательских заметок с тегами и поиском.

## Содержимое репозитория
- `README.md` — описание проекта
- `project-notes.md` — рабочие заметки и roadmap
- `api-plan.md` — план API сервиса

## Запуск (план)
1. Установить зависимости
2. Поднять PostgreSQL
3. Запустить сервер

## Конфликт слияния

Конфликт возник в файле `project-notes.md` при слиянии ветки
`feature/tags` в `main`.

Обе ветки изменяли одну и ту же строку заголовка:
- в `main`: `## Roadmap проекта`
- в `feature/tags`: `## Roadmap заметок`

Конфликт был разрешён вручную: заголовок заменён на
`## Roadmap сервиса заметок`. Исправление зафиксировано
отдельным коммитом `fix: разрешить конфликт слияния в project-notes.md`.
